# IPDF 국제공공디자인포럼 홈페이지

International Public Design Forum 공식 홈페이지 초안.

- 페이지: index(메인), about(포럼 소개), vision(비전과 계획), forums(포럼 아카이브), gallery(갤러리)
- 수정: `_src/content.py`(본문), `_src/build.py`(공통 머리말/꼬리말)를 고친 뒤 `python3 _src/build.py`
- 언어: 한국어 원문 + Google 번역(EN, 中文, 日本語)
- 강조색: IPDF BI Pantone 2216C 딥 틸 `#134B57`, 글꼴 Noto Sans KR
